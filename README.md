# Employee Self Service (ESS)

Employee Self Service application built using React, Node.js, Express, and MySQL.

## Project Structure

- `frontend/` - React frontend
- `Backend/` - Node.js + Express backend
- `Ess_DB.sql` - Database SQL script

## Technologies

### Frontend

- React
- JavaScript
- Tailwind CSS

### Backend

- Node.js
- Express.js
- MySQL

## Features

- Employee Management
- Attendance Management
- Leave Management
- Payroll
- Documents
- E-Sign
- Announcements
